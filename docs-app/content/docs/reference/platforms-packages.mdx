---
title: Supported platforms and packages
description: Contracted release targets and current publication state.
---

Contracted targets are Linux x86-64 and ARM64, macOS x86-64 and Apple Silicon,
and Windows x86-64. No public package channel is released yet. Planned public
channels are GitHub Releases, direct POSIX and PowerShell installers, npm,
Homebrew, and Scoop. A target becomes supported only after its native smoke
test passes.

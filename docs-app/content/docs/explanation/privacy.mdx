---
title: Privacy and retention boundaries
description: Separate Pangram submission, public links, local history, and output redaction.
---

Analysis content is submitted to Pangram. A public dashboard link is opt-in.
Normal output redacts input unless requested. Local history is a separate,
off-by-default plaintext store. Bulk results have a documented 48-hour
upstream retention window. Pangram CLI adds no analytics or telemetry.

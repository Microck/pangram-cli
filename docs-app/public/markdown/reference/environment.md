# Environment variables

| Variable | Effect |
| --- | --- |
| `PANGRAM_API_KEY` | Overrides the stored API key. |
| `PANGRAM_CONFIG` | Selects a configuration file for this invocation. |
| `PANGRAM_DATA_DIR` | Selects the local data directory. |
| `NO_COLOR` | Disables color. |
| `CI` | Disables interactive and automatic-update behavior. |

Environment credentials never enter general configuration output.
